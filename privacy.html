Privacy Policy

Notice: This Privacy Policy outlines the operational and technical data handling practices of Omni Downloader. It should be reviewed by legal counsel before commercial use.

1. Overview & Data Philosophy

Omni Downloader is built around a privacy-preserving, minimal-retention architecture. We do not maintain user accounts, require registration, track behavioral profiles, or sell any user information.

2. Data We Process

In order to provide media extraction and download services, the application processes the following data:

  • Submitted URLs: URLs provided via the input interface are processed in real-time by the backend to query media extractors and retrieve stream manifests. These URLs are not compiled into user profiles.
  • IP Addresses & Rate Limiting: Client IP addresses are stored temporarily in volatile memory using an in-memory sliding window (5 requests per minute) strictly to defend infrastructure against automated denial-of-service attacks. These records are not persistently written to databases.
  • Temporary Media Files: When a download is initiated, media streams are assembled into temporary files in the server filesystem (./downloads/) strictly for immediate retrieval by your browser.
  • Server Technical Logs: Standard HTTP request logs (method, path, status code, error category) are maintained server-side for system health monitoring and debugging. These logs never contain passwords, tokens, or cookie credentials.

3. Authentication & Cookies

Omni Downloader supports optional local cookie files (cookies.txt) for users retrieving media from accounts they are authorized to access. When present:

  • Cookie contents are utilized strictly within local worker threads to communicate with authorized extractors.
  • Cookies are never stored in databases, never transmitted to advertising networks, and never exposed via web APIs or static endpoints.

4. Third-Party Technologies

Media extraction and conversion relies on open-source libraries (yt-dlp and FFmpeg). When a URL is processed, the backend connects directly to the hosting server of that URL. Third-party hosting servers may log standard connection headers according to their respective privacy policies.

5. Data Retention & Disposal

Omni Downloader practices automated data disposal:

  • Temporary media files are automatically removed from the server within 1 hour of creation by a background cleanup routine.
  • In-memory rate limit timestamps expire continuously after 60 seconds.
  • On cloud hosting environments (such as Render Free tier), disk storage is ephemeral and is cleared on container redeployments or restarts.

6. Security Measures

We implement multiple security safeguards to prevent data leakage and system abuse:

  • Server-Side Request Forgery (SSRF) filters preventing queries to internal/private networks.
  • Path traversal prevention and automatic filename sanitization.
  • No client-accessible directory browsing for downloaded files.
